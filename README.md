# Mon portfolio

Portfolio personnel statique, en français, construit avec HTML, CSS et JavaScript sans dépendance à installer.

## Arborescence

```text
mon_portfolio/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── images/
    └── js/
        └── main.js
```

## Aperçu local

Ouvrez `index.html` dans un navigateur. Le site peut aussi être servi par n’importe quel serveur web statique.

## À personnaliser avant publication

1. Remplacez `[Votre nom]`, la présentation et le lieu par vos informations.
2. Remplacez les cartes d’exemple par vos projets, leurs descriptions, technologies et liens.
3. Remplacez `votre.adresse@example.com` par votre adresse courriel.
4. Ajoutez vos images dans `assets/images/` si vos projets en ont besoin.
5. Vérifiez les textes, les liens et l’affichage sur téléphone avant de publier.

La police est chargée depuis Google Fonts; des polices génériques sont prévues en solution de repli.
